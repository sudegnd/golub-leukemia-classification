# golub-leukemia-classification
ALL vs AML gene expression classification
Veri Seti ve Çalıştırma Talimatları
Projede kullanılan veriler üzerinde keşifsel veri analizi öncesinde özel düzenlemeler yapılmıştır. Kodun sorunsuz çalışması için lütfen aşağıdaki adımları izleyin:

[https://drive.google.com/drive/folders/1NESMeU89-jpGl1oPPweDFcip4hwHOsjD?usp=sharing] adresinden ana.zip ve yan.zip dosyalarını indirin.

İndirdiğiniz zip dosyalarını eda_adim4.py betiği ile aynı ana klasöre yerleştirin (Zipten manuel çıkarmanıza gerek yoktur).

Terminalde python eda_adim4.py komutunu çalıştırın. Kod, verileri otomatik bulup çıkaracak ve tüm analiz grafiklerini/tablolarını eda_cikti klasörüne kaydedecektir.
